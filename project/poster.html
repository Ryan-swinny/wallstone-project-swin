Wallstone Coffee & Delivery Portal

A decoupled full-stack web application featuring XML data parsing, shopping automation, and inventory management

System Architecture

Built for COS80021, separating consumer ordering workflows from backend inventory fulfillment.

  • Client-side catalog rendering using asynchronous JavaScript and DOM manipulation.
  • Server-side session tracking and purchase commitment pipelines using PHP.
  • Managerial authentication module ensuring segregated operational privileges.

Project Overview

An end-to-end B2C coffee beans provisioning platform engineered for high accuracy.

  • Live catalog exploration and instant cart balance computation.
  • Two-way state validation between user sessions and warehouse stock.
  • Comprehensive restock and shipment lifecycle tracking for managers.

Data Persistence Design

Lightweight data exchange and state persistence using structured XML hierarchies.

  • Normalized XML nodes decoupling catalog data (`goods.xml`) from users (`customer.xml`).
  • Direct file lock and parse operations handling concurrent customer reads.
  • Strict transactional checkouts preventing overselling on depleted batches.

Technical Implementation

Engineered using vanilla web technologies without heavyweight external framework dependencies.

  • Asynchronous HTTP requests for real-time inventory queries (`getGoods.php`).
  • Server-side transactional cart mutations (`addtocart.php`, `cancel_purchase.php`).
  • Secure manager authorization boundary (`manager_auth.php`).

Key Features

  • Dynamic customer shopping cart with persistent memory.
  • Interactive product catalog featuring fine-grained origin and roast details.
  • Automated stock replenishment calculations for warehouse staff.
  • Granular order cancellation and instant inventory rollback mechanism.

Fulfillment & User Flow

Streamlined workflows reducing operational latency for both buyers and administrators.

  • Zero-refresh cart updates providing desktop-class responsive ordering.

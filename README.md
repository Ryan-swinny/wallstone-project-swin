# Wallstone Coffee & Delivery Portal

A full-stack e-commerce and warehouse replenishment portal developed with vanilla PHP, JavaScript, and XML-based data persistence.

## Key Features
* **B2C Customer Ordering**: Real-time product browsing, interactive shopping cart, and transaction session validation.
* **Inventory Control & Restocking**: Dedicated manager interface to manage catalog items, verify current batches, and trigger restock updates.
* **XML Data Storage**: Decoupled flat-file data persistence eliminating external database server dependencies.

## Tech Stack
* **Backend**: PHP 8 (Procedural & Object-based DOM parsing)
* **Frontend**: Vanilla JavaScript (ES6), HTML5, CSS3
* **Data Layer**: XML (`goods.xml`, `customer.xml`)
* **Environment**: Apache / XAMPP
